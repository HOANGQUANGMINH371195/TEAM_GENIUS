# Canonical evaluation result

Chỉ dùng thư mục `canonical-live-ragas/` để đánh giá dự án.

- `canonical-live-ragas/report.md`: tổng quan và điểm yếu.
- `canonical-live-ragas/failures.md`: toàn bộ failure thật.
- `canonical-live-ragas/summary.json`: thống kê đầy đủ.

Các run thử nghiệm/superseded đã bị xóa để không còn tình trạng report cũ báo PASS giả.
