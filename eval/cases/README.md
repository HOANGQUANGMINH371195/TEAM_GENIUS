# Evaluation case sets

## Super golden snapshot

`super-golden-snapshot-c439751724ab7f10.jsonl` is a release-locked adversarial
set for the active corpus. The first line is a manifest; the remaining 636
lines are cases. It combines exact identifiers, graph/temporal chains,
thematic synthesis, tables, abstention, policy/safety and social routing.

The file is generated by:

```bash
uv run python eval/build_super_golden_dataset.py \
  --release eval/cases/snapshot-c439751724ab7f10.jsonl \
  --semantic data/clean/medical_active_v31_fully_reviewed/semantic_question_benchmark.jsonl \
  --output eval/cases/super-golden-snapshot-c439751724ab7f10.jsonl
```

The release snapshot itself must be regenerated from the canonical source
before this command (the command below preserves signatures and typed gold;
the older hand-shaped snapshot is not a valid accuracy fixture):

```bash
uv run python eval/generate_release_locked_suite.py \
  --dataset-id snapshot-c439751724ab7f10 \
  --release-benchmark data/clean/medical_active_v31_fully_reviewed/release_benchmark.jsonl \
  --semantic-benchmark data/clean/medical_active_v31_fully_reviewed/semantic_question_benchmark.jsonl \
  --output eval/cases/snapshot-c439751724ab7f10.jsonl
```

Graph cases without an explicit direction and source span are marked
`servable=false` and excluded from accuracy denominators until a reviewer
adds those fields; they must never be reported as model failures or passes.

Expected document/relation IDs are inherited from the frozen release benchmark;
the generated paraphrases and distractor instructions are deterministic. The
manifest is marked `human_review_required`: this is a machine-generated
regression gate, not legal-expert approval. Any promotion gate must retain the
dataset hash and active-release fingerprint.

Run the real read-only production-agent benchmark with:

```bash
uv run python eval/run_super_golden_benchmark.py \
  --dataset eval/cases/super-golden-snapshot-c439751724ab7f10.jsonl \
  --output eval/results/super-golden-full-v2.json \
  --limit 0 --concurrency 6
```

The runner scores source selection and answer gates separately, records service
latency after semaphore admission, and records queue latency separately. It
does not claim that a failed source-selection gate means the generated prose is
factually false; use the held-out factual/faithfulness audit for that claim.
